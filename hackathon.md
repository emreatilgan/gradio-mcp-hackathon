## 💡 What is MCP?

Model Context Protocol (MCP) is an open protocol that standardizes how applications provide context to LLMs. MCP enables models to interact with the world. Learn more at [modelcontextprotocol.io](https://modelcontextprotocol.io/introduction).


## 🛠️ Hackathon Tracks

* **🔧 Track 1: MCP Tool / Server**: Did you know that [any Gradio app can also be an MCP server/tool](https://huggingface.co/blog/gradio-mcp)? Extend the capabilities of your favorite LLM by building a Gradio app to accomplish any specific task and share your Space/MCP tool here.  

* **🧩 Track 2: Custom Components for Agents**: Do you wish that a particular Gradio component existed? Would it make your life easier or your agent interfaces more intuitive or powerful if one did? This is your chance to put your Python and JavaScript skills to the test and [create your own Gradio custom component](https://www.gradio.app/guides/custom-components-in-five-minutes) for agent applications.

* **🤖 Track 3: Agentic Demo Showcase**: In this general category, create any kind of Gradio app that demonstrates the power of AI agents (using MCP tools or not). Show us the most incredible things that your agents can do!

See the "Submission Guidelines" section below for more details on each track.

## 🎯 Submission Guidelines

### Track 1: MCP Server / Tool
1. Your submission should be a Gradio app Space [that is also an MCP Server](https://huggingface.co/blog/gradio-mcp)
2. In your Space `README.md`, add the tag: "mcp-server-track"
3. Please also include in your `README.md` a (link to a) video recording of your MCP server in action using any MCP Client (e.g. Claude Desktop, Cursor, Tiny Agents). If you are using another Gradio app as an MCP Client, that is also an acceptable, you can link to that Space. 

### Track 2: Custom Components for Agents
1. Create a [custom Gradio component](https://www.gradio.app/guides/custom-components-in-five-minutes) using Gradio 5 and publish it to Spaces using `gradio cc publish`.
2. In your published Space's `README.md`, add the tag: "custom-component-track"
3. Please also include in your `README.md` a link to a Gradio app or recording of one showing the component in action

### Track 3: Agentic Demo
1. Create a complete Gradio app that showcases any sort of powerful or creative application of AI agents
2. Publish the app on Spaces and in the `README.md`, add the tag: "agent-demo-track"
3. Please also include in your `README.md` a link to a video overview of your app explaining the usage / purpose of the application
